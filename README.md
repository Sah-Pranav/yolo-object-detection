## 📖 Project Overview

This project implements the **YOLO (You Only Look Once)** object detection algorithm to detect objects in autonomous driving scenes using TensorFlow. The implementation demonstrates the complete object detection pipeline, including image preprocessing, confidence thresholding, bounding box prediction, Non-Maximum Suppression (NMS), and visualization of detected objects.

The project showcases practical applications of deep learning for computer vision and provides a hands-on implementation of one of the most influential real-time object detection algorithms.

> **Note:** This project was completed as part of the **DeepLearning.AI Deep Learning Specialization** and has been refined into a portfolio project to demonstrate practical computer vision and deep learning skills.

---

## ✨ Features

- 🚗 YOLO-based real-time object detection
- 📦 Bounding box prediction with confidence scoring
- 🎯 Non-Maximum Suppression (NMS) for duplicate removal
- 🖼️ Image preprocessing and postprocessing pipeline
- ⚡ Inference using pretrained YOLO weights
- 📊 Visualization of detected objects
